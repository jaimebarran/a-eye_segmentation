# 👁️ A-eye: Segmentation

This submodule provides the **deep learning segmentation pipelines** for automated 3D MRI segmentation of the eye and orbit structures.  

It includes:

- nnU-Net training configurations
- Inference and evaluation scripts  
- Atlas registration and construction scripts

Pretrained weights (`Task313_Eye`) are available on **[Zenodo](https://doi.org/10.5281/zenodo.13325371)** and can be installed into any nnU-Net environment, or used directly via the ready-to-use [Docker image](https://hub.docker.com/repository/docker/jaimebarran/fw_gear_aeye).

---

Part of the **A-eye** project — automated 3D MRI segmentation and morphometric feature extraction for eye and orbit atlas construction, published in [*PLOS ONE*](https://doi.org/10.1371/journal.pone.0352257).

Try the pipeline online at **[aeye.hevs.ch](https://aeye.hevs.ch)**, or see the main repository for the complete documentation, visual figures, and citation info:  
👉 [A-eye main repository](https://github.com/jaimebarran/a-eye)
